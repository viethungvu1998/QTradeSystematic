## Fundamental Data Architecture

### Release Lag Rule

> **Critical — vi phạm gây look-ahead bias.**

**`available_from = (period_end + 5 tháng).replace(day=1)`** — áp dụng cho cả annual và quarterly.

| Loại | Period end | available_from |
|------|-----------|----------------|
| Q1 quarterly | 31/03 | **01/08** |
| Q2 quarterly | 30/06 | **01/11** |
| Q3 quarterly | 30/09 | **01/02 năm sau** |
| Q4 quarterly | 31/12 | **01/05 năm sau** |
| Annual FY | 31/12 | **01/05 năm sau** |

```
❌ merge_asof(right_on="period_end")     → look-ahead
✅ merge_asof(right_on="available_from") → đúng
```

Ví dụ: trade_date = 2024-07-15 — chỉ thấy Q4/2023 (available 01/05/2024); Q1/2024 (available 01/08/2024) chưa được dùng.

---

### Annual vs Quarterly

| | Annual | Quarterly |
|---|---|---|
| Tần suất | 1/năm | 4/năm |
| Độ tin cậy | Cao (kiểm toán) | Thấp hơn |
| Use case | Balance sheet, full-year P&L | Revenue trend, profit momentum |
| Transformation | `YoYAnnualTransformer` | `SameQuarterYoYTransformer` + `TTMTransformer` |

## ML Model Specification

### Price Features — Log Return

> **Tất cả price-based features phải dùng log return, không dùng price level hay simple return.**

```
log_ret_n = log(close_t / close_{t-n})
```

Lý do:
- **Scale-free**: log(2×) = log(2) bất kể giá cổ phiếu là 10k hay 100k VND
- **Additive theo thời gian**: log_ret_5d = log_ret_1d × 5 (gần đúng)
- **Symmetric**: +10% và -10% có magnitude tương đương (price return thì không)
- **Stationary**: dễ train hơn với tree models và normalization

Các FeatureBuilder phải tuân thủ:
```
MomentumFeatures → mom_21 = log(close / close.shift(21))
VolatilityFeatures → vol_21 = std(log(close / close.shift(1)), window=21)
```
Raw price level KHÔNG được đưa vào feature set.

---

### Label Schema — 5 Classes

```
Class 0 — Strong Bear   (bottom quintile, worst performers)
Class 1 — Weak Bear
Class 2 — No Change     (middle)
Class 3 — Weak Bull
Class 4 — Strong Bull   (top quintile, best performers)
```

**Default labeling**: Cross-sectional quantile tại mỗi rebalance date trong training slice.
- "Strong Bull" = top 20% performers trong cross-section tại ngày đó
- Robust: adapts to market regime, không bị bias bởi bull/bear market tổng thể

**Alternative**: `ThresholdLabeler` dùng return thresholds tuyệt đối.

---

### Strategy Rule (Out-of-Sample từ 2024-01-01)

```
Holding period:    21 trading days
Signal:            Chỉ class 4 (Strong Bull) — không trade class 0-3
Max positions:     5
Weighting:         Fixed-slot equal weight = 1 / max_positions = 20% mỗi slot
Cash buffer:       Slots không có Strong Bull signal → giữ tiền mặt
                   Ví dụ: 3 Strong Bull → 60% invested, 40% cash

Entry:             Rebalance date t: predict class, lấy top-5 Strong Bull theo probability
Exit:              Rebalance date t + 21 (hoặc khi bị đẩy ra khỏi top-5)
Short:             Không (long-only)
```

Ví dụ cụ thể:
```
Rebalance 2024-03-01:
  Strong Bull signals: VCB (prob=0.71), FPT (prob=0.65), MBB (prob=0.58)
  → 3 positions × 20% = 60% invested, 40% cash
  
Rebalance 2024-03-22:
  Strong Bull signals: VCB, FPT, MBB, HPG, CTG
  → 5 positions × 20% = 100% invested
  
Rebalance 2024-04-12:
  Strong Bull signals: (none)
  → 0% invested, 100% cash
```

## Protocols & Abstractions

```python
from typing import Protocol, Callable, Literal
import pandas as pd

class FeatureBuilder(Protocol):
    def build(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Nhận merged df, trả về df chỉ chứa feature columns mới.
        CONTRACT: tất cả price features PHẢI dùng log return, không dùng price level.
        Không mutate input.
        """
        ...

class FundamentalTransformer(Protocol):
    def transform(self, wide_df: pd.DataFrame) -> pd.DataFrame:
        """
        Nhận wide-form fundamental DataFrame đã có available_from.
        Thêm cột YoY/QoQ/TTM. KHÔNG thay đổi available_from. Không mutate.
        """
        ...

class LabelScheme(Protocol):
    def encode(
        self,
        forward_returns: pd.DataFrame,  # shape: (dates × symbols)
    ) -> pd.DataFrame:
        """
        Chuyển forward return thành integer class label {0,1,2,3,4}.
        Encode được tính TRONG training slice (không toàn dataset).
        """
        ...

class FundamentalFilter(Protocol):
    def mask(self, df: pd.DataFrame) -> pd.Series:
        """Trả về boolean Series — True = giữ symbol tại ngày đó."""
        ...

class Predictor(Protocol):
    def fit(self, X: pd.DataFrame, y: pd.Series, **kwargs) -> None: ...
    def predict_proba(self, X: pd.DataFrame) -> pd.DataFrame:
        """Trả về DataFrame shape (n_samples, n_classes), columns = [0,1,2,3,4]."""
        ...

class Weighter(Protocol):
    def compute(
        self,
        selected: list[str],
        max_positions: int,
        prices: pd.DataFrame,
        scores: pd.Series,
    ) -> dict[str, float]:
        """
        Trả về {symbol: weight}.
        Fixed-slot: weight = 1/max_positions per symbol (không phải 1/len(selected)).
        Tổng có thể < 1.0 khi selected < max_positions → phần còn lại là cash.
        """
        ...

ObjectiveFn = Callable[["BacktestResult"], float]
```

**Tại sao `predict_proba` thay vì `predict_score`**:  
Strategy cần biết cả class prediction VÀ probability để rank trong cùng class. `predict_proba` trả về full distribution — caller tự extract class và probability.

### `LabelScheme` Built-in Implementations

```
CrossSectionalQuantileLabeler(n_classes=5)
    Labeling: tại mỗi date trong training slice, rank forward_return cross-sectionally
              → quintile 0–4 = Strong Bear → Strong Bull
    Đặc điểm: label distribution luôn balanced (~20% mỗi class) → tốt cho mlogloss
    Dùng cho: VN100 quantamental (default)
    Thận trọng: label có nghĩa TƯƠNG ĐỐI — "Strong Bull" = top 20% của cross-section,
               không nhất thiết là positive return trong bear market

ThresholdLabeler(thresholds: list[float] = [-0.05, -0.01, 0.01, 0.05])
    Labeling: absolute return thresholds
              < -5%  → 0 (Strong Bear)
              -5% to -1% → 1 (Weak Bear)
              -1% to +1% → 2 (No Change)
              +1% to +5% → 3 (Weak Bull)
              > +5%  → 4 (Strong Bull)
    Đặc điểm: label distribution unbalanced (market-regime dependent)
               → cần class_weight balancing trong XGBoost
    Dùng cho: absolute return targeting, market-neutral strategies
```

### `FundamentalTransformer` Built-in Implementations

```
YoYAnnualTransformer(metrics: list[str])
    Áp dụng: annual_wide
    Logic: per symbol, shift(1) = năm N-1
        df[f"{m}_yoy"] = (df[m] - df[m].shift(1)) / df[m].shift(1).abs()
    Output cols: revenue_yoy, net_profit_yoy, total_assets_yoy, ...
    available_from: không thay đổi (YoY của FY2024 = available_from FY2024)

SameQuarterYoYTransformer(metrics: list[str])
    Áp dụng: quarterly_wide
    Logic: per symbol, shift(4) = cùng quý năm trước
        df[f"{m}_q_yoy"] = (df[m] - df[m].shift(4)) / df[m].shift(4).abs()
    Tại sao shift(4) không phải shift(1):
        shift(1) = QoQ sequential → bị seasonality (Q1 vs Q4)
        shift(4) = same-quarter YoY → loại seasonality → đúng định nghĩa user
    Output cols: revenue_q_yoy, net_profit_q_yoy, operating_profit_q_yoy
    available_from: không thay đổi (YoY của Q1/2024 = 01/08/2024 = khi cả hai period available)

TTMTransformer(metrics: list[str])
    Áp dụng: quarterly_wide
    Logic: rolling sum 4 quarters per symbol
        df[f"{m}_ttm"] = df.groupby("symbol")[m].transform(
            lambda x: x.rolling(4, min_periods=4).sum()
        )
    Output cols: revenue_ttm, net_profit_ttm, operating_profit_ttm
    Dùng: tính ROE TTM, P/E TTM thay vì số quý lẻ
    available_from: không thay đổi

CompositeTransformer(transformers: list[FundamentalTransformer])
    Gọi tuần tự, output của transformer N là input của N+1.
    Ví dụ: TTM trước → YoY trên TTM:
        CompositeTransformer([TTMTransformer(["Revenue"]), YoYAnnualTransformer(["Revenue_ttm"])])
```

### `merge_fundamentals_asof`

```
Signature:
    merge_fundamentals_asof(
        prices: pd.DataFrame,
        annual_features: pd.DataFrame,
        quarterly_features: pd.DataFrame,
    ) -> pd.DataFrame

Output:
    prices + annual + quarterly columns, MultiIndex (date, symbol)
    Overlapping metric names: suffix _a (annual), _q (quarterly)
    Auxiliary cols (fiscal_year, quarter, available_from) dropped

Behavior:
    Với mỗi symbol:
        Step 1: merge_asof(prices, annual_features, left_on="date",
                           right_on="available_from", direction="backward")
        Step 2: merge_asof(result, quarterly_features, left_on="date",
                           right_on="available_from", direction="backward")
    Concat symbols, return

No-look-ahead guarantee (3 tầng):
    1. available_from = period_end + 5 tháng (release lag)
    2. merge_asof direction="backward": trade_date chỉ thấy available_from <= trade_date
    3. YoY/QoQ tính pre-merge: shift(4) dùng đúng available_from logic của row hiện tại

Rows dropped:
    Rows có trade_date trước available_from đầu tiên của CẢ HAI annual và quarterly
```

### `walk_forward_predict`

```
Signature:
    walk_forward_predict(
        df: pd.DataFrame,
        predictor: Predictor,
        config: RunConfig,
        feature_cols: list[str],
    ) -> pd.DataFrame

Output:
    pd.DataFrame: date, symbol, pred_class (int), prob_strong_bull (float)
    Chỉ rows tại rebalance dates >= config.test_start_date

Behavior:
    1. Tìm rebalance dates: mỗi config.rebalance_period ngày
       Chỉ predict tại dates >= config.test_start_date
    2. Với mỗi rebalance date t >= test_start_date:
        a. Train slice: df[t - train_window : t]  (exclusive t)
        b. predictor.fit(X_train, y_train)
        c. proba = predictor.predict_proba(X_t)   shape: (n_symbols, 5)
        d. pred_class = proba.idxmax(axis=1)
        e. prob_strong_bull = proba[4]  (column 4 = Strong Bull)
        f. Append (t, symbol, pred_class, prob_strong_bull)

Out-of-sample split:
    - Training data bao gồm toàn bộ lịch sử TRƯỚC t (rolling window)
    - Predictions chỉ từ test_start_date = 2024-01-01
    - Không có data leakage: tại t=2024-01-01, train trên [2024-01-01 - train_window, 2024-01-01)
      = toàn bộ in-sample period

No-look-ahead guarantee:
    Train slice [t - train_window, t) không bao gồm ngày t.
    predictor không access data sau t.

Notes:
    - Output có cả pred_class VÀ prob_strong_bull
    - pred_class dùng để filter (chỉ take class 4)

```

## Portfolio Layer

### `build_portfolio_weights`

```
Signature:
    build_portfolio_weights(
        predictions: pd.DataFrame,
        prices: pd.DataFrame,
        filter_set: FundamentalFilter,
        weighter: Weighter,
        config: RunConfig,
    ) -> pd.DataFrame

Input:
    predictions — DataFrame [date, symbol, pred_class, prob_strong_bull]
                  từ walk_forward_predict
    prices      — OHLCV
    filter_set  — FundamentalFilter (loại bỏ symbols kém chất lượng)
    weighter    — Weighter object
    config      — dùng signal_class, max_positions

Output:
    pd.DataFrame: date, symbol, weight
    Constraint: weight = 1/max_positions mỗi slot, tổng <= 1.0

Behavior:
    Với mỗi rebalance date t:
        Step 1 — Fundamental filter:
            eligible = symbols pass filter_set.mask(df_at_t)
        Step 2 — Signal class filter:
            signals = eligible WHERE pred_class == config.signal_class (== 4)
        Step 3 — Rank và select:
            selected = signals.nlargest(config.max_positions, "prob_strong_bull")
        Step 4 — Weight via fixed-slot:
            weighter.compute(selected, config.max_positions, prices, scores)
            → {symbol: 1/max_positions}  mỗi symbol
        Step 5 — Append result

Cash buffer logic:
    Nếu len(selected) < max_positions:
        → sum(weights) < 1.0 → phần còn lại là cash (không invest vào class khác)
    Nếu len(selected) == 0:
        → tất cả là cash tại ngày đó

Ví dụ:
    max_positions=5, Strong Bull signals tại t: [VCB, FPT, MBB]
    → weights: {VCB: 0.20, FPT: 0.20, MBB: 0.20}
    → cash: 0.40 (2 slots trống)
```

### Built-in Weighters

```
FixedSlotEqualWeighter()
    compute(selected, max_positions, prices, scores)
    → {s: 1/max_positions for s in selected}
    Tổng = len(selected)/max_positions ≤ 1.0
    DEFAULT cho VN100 quantamental

InverseVolWeighter(lookback=21)
    compute(selected, max_positions, prices, scores)
    → weights tỷ lệ nghịch với vol_lookback
    Normalize để tổng = len(selected)/max_positions (giữ đúng cash buffer)
    Dùng khi muốn risk-adjusted sizing trong các slots đã chọn
```

## Optimization Layer

### `ObjectiveFn` Factories

```python
def cagr_with_drawdown_penalty(max_dd_limit: float = 0.30) -> ObjectiveFn:
    def _obj(result: BacktestResult) -> float:
        if result.max_drawdown > max_dd_limit:
            return float("-inf")
        return result.cagr
    return _obj

def calmar_objective() -> ObjectiveFn:
    def _obj(r: BacktestResult) -> float: return r.calmar
    return _obj

def sharpe_objective() -> ObjectiveFn:
    def _obj(r: BacktestResult) -> float: return r.sharpe
    return _obj
```

```
Signature:

Notes:

Pipeline (12 bước):
    1.  load_prices(universe, start, end) → prices
    2.  load_fundamentals(universe, "annual") → annual_long       [preflight annual]
    3.  load_fundamentals(universe, "quarterly") → quarterly_long  [preflight quarterly]
    4.  pivot_fundamentals(annual_long, "annual") → annual_wide
    5.  pivot_fundamentals(quarterly_long, "quarterly") → quarterly_wide
    6.  build_fundamental_features(
            annual_wide, quarterly_wide,
            annual_transformers, quarterly_transformers,
        ) → (annual_features, quarterly_features)
    7.  merge_fundamentals_asof(prices, annual_features, quarterly_features) → merged
    8.  build_features(merged, builders) → featured
    9.  feature_cols = [c for c in featured.columns if c not in OHLCV_COLS + AUX_COLS]
    10. make_training_frame(featured, config.target_horizon, feature_cols, labeler) → labeled
    11. Định nghĩa run_fn(params):
            predictor = predictor_factory(params)
            cfg       = dataclasses.replace(config, **params_subset)
            preds     = walk_forward_predict(labeled, predictor, cfg, feature_cols)
            weights   = build_portfolio_weights(preds, prices, filter_set, weighter, cfg)
            return    run_backtest(weights, prices, cfg)
    12. run_optuna(run_fn, search_space, objective, ...) → result
        save_outputs(result, config.output_dir)

Output files (6):
    best_params.json, trials.csv, weights.csv,
    metrics.csv, equity_curve.png, drawdown.png
```
